How-to

Get Started

1

Choose Filters

Select a programming language and a topic category from the dropdowns, or leave both empty for a completely random draw from GitHub's universe.

2

Hit Discover

Click the Discover button. Repo Finder queries the GitHub API with randomised parameters and returns a repository you've likely never seen before.

3

Explore & Repeat

Review the full metadata — stars, language, topics, description. If it sparks interest, open it on GitHub. If not, click discover again.
